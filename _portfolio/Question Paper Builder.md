# Question Paper Builder

## Overview
A desktop application built for teachers to compose and format exam question papers through a graphical interface, cutting paper preparation time from hours to under 15 minutes.

## Key Features
- Graphical interface for composing question papers
- Formatted output suitable for printing
- Question bank management
- Customizable paper templates

## Technologies Used
- C++
- Qt Framework
